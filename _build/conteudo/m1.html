01
Onde este módulo acontece

São três Claude, e este módulo mora no primeiro

No nivelamento você pedia, e ele respondia. Cada resposta voltava para a sua mão: você lia, conferia, copiava. Aqui o método sai do teclado e passa a morar em um lugar que a ferramenta lê sozinha. O nivelamento mostrou o que cada Claude alcança. Agora a pergunta é outra e mais direta: para quem cada um foi feito.

para todos

Claude Chat

Conversar, pensar, escrever
Você usa para
  • Pensar em voz alta e destravar uma decisão
  • Escrever e revisar ofício, parecer, comunicado
  • Entender um documento que chegou
  • Guardar as regras da tarefa que volta toda semana
É este módulo. Nada para instalar além do aplicativo, e é onde a conferência documental passa o dia.
para quem não é técnico

Claude Cowork

Agir nos seus arquivos e tarefas
Você usa para
  • Trabalhar na pasta onde o relatório já cai, sem anexar nada
  • Tratar dezenas de arquivos de uma vez, não um por um
  • Alcançar as ferramentas onde o trabalho já acontece
  • Deixar a rotina rodando numa cadência
É o encontro 3. Você libera o acesso uma vez, e ele executa.
para quem programa

Claude Code

Construir o que continua funcionando
Você usa para
  • Montar um painel que se atualiza sozinho
  • Escrever a conferência que roda antes de você assinar
  • Guardar versões e voltar atrás quando erra
  • Ligar sistemas que não têm conector pronto
É o encontro 4, e você não vai programar lá também. Vai pedir, e conferir.
Chat

é para pensar com ele.

Cowork

é para delegar para ele.

Code

é para construir com ele.

A diferença que mais pesa no seu dia é a do meio. No Chat você anexa um arquivo e recebe um texto de volta. No Cowork ele mexe no arquivo que já está lá e devolve outro arquivo, salvo na sua pasta. Este módulo inteiro acontece no primeiro, e é de propósito: o que você aprender aqui atravessa os três.

02
O que tem dentro

As cinco aulas do Módulo 1

O nivelamento terminou com você pedindo bem, conferindo o que volta e com um perfil salvo na conta. Este módulo pega esse método e tira ele do teclado: o que você escrevia em todo pedido passa a morar em um lugar que a ferramenta lê sozinha, e a regra deixa de ser sua para ser da função.

São cinco aulas, e cada uma tem um conceito só. O título de cada uma diz o resultado que você leva, e não o assunto. As quatro cláusulas da ementa aparecem no selo cinza de cada cartão.

Uma palavra que atravessa as cinco

Quando este módulo diz assistente, ele está falando de um projeto: aquela pasta com as suas regras escritas dentro, que ele lê no começo de toda conversa daquele trabalho. Não é outro produto nem outro botão, e é o que o módulo inteiro monta.

Aqui o Claude Desktop entra

O nivelamento rodou no que você já tinha aberto. A partir deste módulo o material aponta para tela, e o aplicativo instalado passa a ser o lugar onde as coisas acontecem.
